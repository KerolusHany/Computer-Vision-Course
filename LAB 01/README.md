# Computer Vision Lab 01

This folder contains the Colab-ready notebook, the original input images, the four generated output images, and the Word report.

## Run the notebook

1. Open `Lab01_Computer_Vision.ipynb` from the GitHub repository in Google Colab.
2. Run the cells from top to bottom. The notebook clones this repository when the input images are not already in the runtime.
3. The processed PNG files are written to `outputs/`.

## Folder contents

- `Lab01_Computer_Vision.ipynb` — notebook implementing all four tasks.
- `images/` — supplied input images.
- `outputs/` — generated outputs for Tasks 1–4.
- `Lab01_Computer_Vision_Report.docx` — lab report.
